S&B ENTERPRISES PROFESSIONAL ERP — INSTALLABLE PWA
===================================================

यह build मोबाइल और computer दोनों में application की तरह install होने के लिए तैयार है।

IMPORTANT:
PWA install के लिए software को HTTPS website/domain से खोलना जरूरी है।
सिर्फ ZIP खोलकर file:// से खोलने पर Install App विकल्प नहीं आएगा।

MOBILE (Android/Chrome):
1. Software को HTTPS link से खोलें।
2. ऊपर “Install App” दबाएँ या Chrome menu → Install app / Add to Home screen चुनें।
3. Home screen पर S&B ERP app बन जाएगा।

COMPUTER (Chrome/Edge):
1. HTTPS link से software खोलें।
2. Address bar के Install icon या software के “Install App” button को दबाएँ।
3. Windows/macOS/Linux पर standalone app की तरह खुलेगा।

- Payments / Receipts
- Customers / Suppliers
- Products / Stock

- Reports

- Backup / Restore
- A4 1-page PDF invoice

DATA:
इस version में data उसी device/browser के local storage में रहता है और backup/restore उपलब्ध है।
Mobile और computer के बीच automatic same-data sync के लिए cloud server/account setup अलग चरण में जोड़ना होगा।

CA/COMPLIANCE NOTE:
यह professional accounting/ERP foundation है। GST return filing, e-invoice/e-way bill और tax compliance के लिए current government rules और CA review जरूरी हैं; software को statutory filing authority न मानें।
